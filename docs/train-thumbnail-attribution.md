# Task thumbnail sample photo credits

These three Wikimedia Commons photographs are used as decorative task-list thumbnails only when the task has no usable evidence image. The card labels them **Sample**; they are not defect evidence and are not saved to the task or backend.

- [Indian Railways Train in 2025](https://commons.wikimedia.org/wiki/File:Indian_Railways_Train_in_2025.jpg), Ash7876. CC BY 4.0. Wikimedia-generated 640 px thumbnail.
- [Tracks-train.JPG](https://commons.wikimedia.org/wiki/File:Tracks-train.JPG), Rakesh.5suthar. CC BY-SA 3.0. Wikimedia-generated 640 px thumbnail.

If a remote sample image cannot load, the UI shows its local inline train illustration instead.
